{扱うデータ、状態の持ち方、ライフサイクル} 🔵/🟡

ルール:

- 各記述に信頼性マーカー（🔵 根拠あり / 🟡 推定 / 🔴 要確認）を付ける。承認時に 🟡・🔴 が残っていてはならない
- 書くべき内容がない節は「特になし」ではなく節ごと削る（例外: 「構造図」と「技術的負債の方針」は必須。負債が無い場合は「なし」と明記する）
- 書くのは今の構造とその意図で、やり取りの過程と、Issue ごとの AC の対応は書かない
- 同じ対象に既存の設計書があるときは、この文書を正とする。既存の設計書には手を付けない
